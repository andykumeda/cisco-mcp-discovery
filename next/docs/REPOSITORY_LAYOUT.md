# Repository layout

This repository is the single public portfolio source.

- `next/`: later recovered application source, tests and fictional examples. Use this for future work on the expanded MCP tools.
- Root `cisco_mcp/`: earlier implementation and its smaller offline demo, retained so the verified demo stays reproducible.
- Private inventory, credentials and collected artifacts: outside the repository in user-selected locations.
- Original working files/history: preserved in a separate private recovery archive; never merge or publish them.

The public application uses portable paths and disabled live access. Read next/README.md for the different command/discovery policy and remaining live-use limitations. This is a recovered prototype, not a configured deployment.
